# Compensation Intelligence Platform

A structured compensation intelligence platform focused on comparing compensation by:

- Role
- Canonical level
- Location
- Base salary
- Bonus
- Equity
- Total compensation

## Data

The current dataset is synthetic/demo data created for development and demonstration purposes.

It is not presented as verified salary data from Levels.fyi, 6figr, AmbitionBox, or Glassdoor.
